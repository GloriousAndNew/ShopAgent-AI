# 入门练习

这部分用于学习，不是正式 ShopAgent 应用。完整操作步骤见 [第一天操作手册](../docs/新手指南/02-第一天操作手册.md)。

- hello.py：运行并修改第一个 Python 程序。
- product_filter.py：学习商品数据、函数、预算筛选。
- first_api.py：将商品筛选接到浏览器，用 FastAPI 返回 JSON。
- requirements.txt：练习接口使用的已验证依赖版本。

2026-10-09 验证记录：使用现有 Python 3.13 运行 hello 和筛选练习；在临时虚拟环境中使用 FastAPI 0.143.0、Uvicorn 0.54.0 检查健康接口、默认预算、100 元预算、空结果、负预算 422 和自动接口文档，均通过。临时验证未给你的全局 Python 安装这些包；按手册创建项目 .venv 后安装即可。

此练习只读内存中的商品，没有登录、数据库、模型或模块热插拔。商品价格为整数分，接口的 max_price 参数为整数元。
