# 顾客入口与人工回复：一步步体验

日期：2026-10-09。当前在你电脑本地试运行，尚未部署公网。

## 先分清三个链接

| 链接 | 给谁使用 | 用途 |
|---|---|---|
| http://127.0.0.1:8000/customer | 顾客体验 | 不注册，点击开始咨询；查商品、库存、优惠与政策，联系人工 |
| http://127.0.0.1:8000/merchant | 商家 | 登录管理员，维护资料，查看咨询并回复 |
| http://127.0.0.1:8000/ | 开发演示 | 保留 Alice / Bob 示例订单与完整流程测试 |

顾客入口没有示例账号选择和示例订单快捷按钮。访客的工具权限由服务器限制，不能通过接口查询示例订单、物流、会员或提交售后。相关需求登记人工咨询，由商家核实。

这些链接现在只能在这台电脑上使用。`127.0.0.1` 是“当前这台电脑”，外部顾客打不开你电脑的这个地址；部署后才能分享域名链接。

## 顾客怎么用

1. 打开顾客入口，点击“开始咨询”，无需注册。
2. 输入问题，或者点击商品与政策问题示例。资料仍含示例，真实模型调用仍按你本地配置的服务计费。
3. 需要商家处理时，点击“联系人工客服”，描述问题，再点击“提交人工咨询”。提交直接登记，不需要等模型，也不调用模型发送消息。
4. 当前会话会附给商家。不要在问题里填写密码、支付凭据、完整身份证等不必要的信息。
5. 在“我的人工咨询”看状态；收到回复会显示未读数量。页面保持打开且可见时，每30秒检查未读提示；它不会自动替换聊天内容。
6. 点击“打开会话查看回复”，人工回复会标注“商家客服 · 人工回复”。打开会话后相应消息才标记已读。
7. 在当前聊天点击“查看客服回复”，只追加新的人工回复，保留正在输入的问题和当前售后确认草稿。

访客凭据8小时内有效，保存在当前浏览器标签页的会话存储中。刷新通常可以继续；退出会撤销当前凭据，关闭标签页或凭据过期后不能保证恢复咨询。当前没有找回会话、跨设备登录或短信/邮件提醒，不能承诺“明天用任何设备都能查看”。

## 商家怎么回复

1. 打开商家入口，当前本地示例管理员为 Admin，密码 `demo123`。这仍是演示账号，不应公开到公网。
2. 进入“商家后台”，找到“顾客咨询与人工回复”。默认显示待处理咨询，可以切换已回复、已关闭或全部。
3. 展开“查看会话与回复记录”，查看最近20条聊天，包括顾客问题、AI/系统答复与人工回复。超出这20条的记录仍在会话库中；这里不是完整历史导出。
4. 在对应咨询下输入回复，点击“发送人工回复”。系统将回复保存到顾客原会话，避免发到别人的会话。
5. 已回复不等于处理结束，可以继续回复。发送后页面显示当前状态；刷新或重新筛选后列表会更新分类。
6. 处理结束点击“关闭咨询”。关闭后不能发送新的回复，历史仍保留。
7. 需要继续处理就点击“重新打开”，恢复待处理状态后再回复。状态变更有操作记录；其他页面已修改状态时，会要求刷新。

回复失败时，可用原内容重试；同一提交编号会防止重复保存。不要把“回复已保存”理解为顾客已读；未读状态属于顾客查看流程，当前商家界面不承诺展示每条消息的送达回执。

## 你现在可以照着验收

打开两个页面：一个顾客入口，一个商家入口。

1. 顾客登记“想确认耳机是否适合通勤”。
2. 商家在待处理列表找到它，展开会话并回复“已收到，请补充需求”。
3. 顾客打开我的人工咨询，检查未读提示。
4. 打开原会话，确认只有自己的回复，未读提示消失。
5. 商家关闭咨询，确认回复框禁用；重新打开后回复框恢复。

本轮已通过网页验证这一闭环，也验证了手机尺寸显示和“刷新回复不清空未发送文字”。测试记录明确写了“网页验收”，不会冒充真实顾客咨询。

## 已加上的运行保护

当前为单宿主进程保护：同一个直连IP每分钟最多30次登录尝试，每小时最多10次新建访客；访客每小时最多60次模型咨询，示例登录用户每小时最多300次咨询；每个身份每小时最多10次人工登记；全站最多接纳8个正在处理或排队的聊天请求。

限流达到上限返回429，不会继续调用模型。重启会清空内存窗口。反向代理部署后，默认看到的是代理IP；目前不信任随意传来的 `X-Forwarded-For`，需配置可信代理和网关限流。多个实例不能共用这份内存限额。

动态页面与接口标为不缓存，页面限制嵌入，浏览器仍按不可信文字显示顾客与客服内容。凭据不显示在网页内容中，也没有放进URL。
