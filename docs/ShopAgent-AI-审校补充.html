实证简历表述｜20k/30k/40k 三档

本节是优先使用的审校版，前提是本人实际完成相应工作。原文任何平台规模、收益、准确率或上线数字均为教学叙事/示例，未实测不得复制为本人经历；40k也仅表示贡献深度，不保证薪资。

20k｜基础交付

  • 围绕商品、交易与售后信息分散，客服和运营需要在版本与权限边界内核对事实，完成智能电商客服 Agent（ShopAgent AI）个人/教学项目的基础版本；使用Python, LangChain, FastMCP, python-a2a, FastAPI, MySQL, Docker搭建从输入到可核查输出的主流程。
  • 以公开或合成商品目录、商品详情、订单状态样例、售后政策与FAQ的公开或合成样本完成数据接入、接口联调及正常/异常演示，提交代码、启动说明和测试记录。

30k｜评测迭代

  • 负责智能电商客服 Agent（ShopAgent AI）的MCP Server → A2A Agent → API Server 三层架构链路拆解与迭代；冻结测试集，分别记录质量、延迟和失败样本，而非只展示成功案例。
  • 针对错误召回、版本冲突或模型幻觉设计拒答、证据校验和人工接管；保存基线与改版的同集对比。

40k｜系统设计

  • 主导智能电商客服 Agent（ShopAgent AI）的业务边界、数据契约和系统架构设计，明确模型与确定性规则、人工审批之间的责任划分。
  • 补充租户/角色权限、工具幂等、超时降级、日志追踪、版本发布与回滚；用故障演练和冻结集验收证明可交付性。
  • 根据本人实际承担的范围陈述架构取舍与协作成果；没有真实上线证据时明确说是教学MVP或受控试点。
