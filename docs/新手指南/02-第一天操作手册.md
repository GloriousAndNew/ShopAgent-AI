# 第一天操作手册：运行第一个程序和商品接口

目标：能运行 Python 文件；进一步能在浏览器看到程序返回的商品数据。所有数据都是练习样本，不涉及真实商家。

## 1. 打开项目文件夹

打开 VS Code，点“文件 → 打开文件夹”，选择：

```text
C:\Users\44332\Documents\ChatGPT\智能电商客服
```

左侧应看到 `docs` 和 `learning_examples`。文件夹是存文件的地方，VS Code 是编辑文件的工具，Python 是运行代码的工具。

点“终端 → 新建终端”，选择 PowerShell。终端是输入命令的窗口；不要把命令粘贴到 Python 文件里。

本页的 `powershell` 代码块是终端命令。逐行复制、按回车执行，不要复制代码块外的标题或说明。文件代码已经准备好，不需要你重新粘贴一遍。

## 2. 切换到正确目录并确认 Python

```powershell
Set-Location -LiteralPath 'C:\Users\44332\Documents\ChatGPT\智能电商客服'
Get-Location
py -3.13 --version
```

预期：路径为上面的项目文件夹，版本以 `Python 3.13` 开头。最后的小版本数字可以不同。

`Set-Location` 是“进入文件夹”；`py -3.13` 是“选用 Python 3.13”。这台电脑直接输入 `python` 会选到旧的 3.7，所以不要用裸 `python` 命令代替手册命令。

## 3. 先运行最小程序

```powershell
py -3.13 -X utf8 .\learning_examples\hello.py
```

预期输出：

```text
你好，ShopAgent AI！
我正在学习写程序。
```

点开 `learning_examples/hello.py`，把第二行的中文改成“这是我第一次运行 Python”，按 `Ctrl+S` 保存，再执行同一条命令。看到输出改变，就理解了“改文件 → 保存 → 运行”。

完成这里就可以休息。后面的接口需要先安装两个工具包。

## 4. 创建项目专用的工具箱

在项目目录执行一次：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe --version
```

预期：创建 `.venv` 文件夹，第二条命令输出 `Python 3.13.x`。

`.venv` 叫虚拟环境，可以理解成“这个项目专用的 Python 和工具箱”。它让不同项目安装的工具互不干扰。无需每次运行都重新创建。这个原理和创建方式见 [Python 官方中文说明](https://docs.python.org/zh-cn/3.13/tutorial/venv.html)。

本手册直接指定 `.venv` 里的程序路径，不要求运行 `Activate.ps1`，也不需要修改 PowerShell 执行策略。

## 5. 安装做接口需要的两个工具包

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\learning_examples\requirements.txt
.\.venv\Scripts\python.exe -m pip show fastapi uvicorn
```

需要联网。第一条安装工具；第二条显示名称、版本和安装位置，位置应包含当前项目的 `.venv`。

- `pip`：Python 的工具包安装器。
- `FastAPI`：帮你写“浏览器请求后返回数据”的接口。
- `Uvicorn`：让 FastAPI 程序持续运行、接收请求。

不要改用裸 `pip install`，避免把包装到旧 Python 中。requirements.txt 已固定本次验证通过的 FastAPI 0.143.0 和 Uvicorn 0.54.0。成功运行后还可以记录全部依赖版本，方便以后复现。

## 6. 让 VS Code 也选对 Python

如果 VS Code 还没有 Microsoft 发布的 Python 扩展，在左侧“扩展”搜索 `Python`，确认发布者为 Microsoft 后安装。

按 `Ctrl+Shift+P`，输入 `Python: Select Interpreter`，选择当前项目 `.venv\Scripts\python.exe`。没有看到时选择“输入解释器路径”，填：

```text
C:\Users\44332\Documents\ChatGPT\智能电商客服\.venv\Scripts\python.exe
```

选择解释器关系到编辑器的提示和运行按钮；终端中仍按手册完整命令执行。官方说明见 [VS Code Python 环境文档](https://code.visualstudio.com/docs/python/environments)。

## 7. 启动练习服务

确认终端仍在项目文件夹，执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m uvicorn learning_examples.first_api:app --host 127.0.0.1 --port 8000 --reload
```

预期：终端出现类似 `Uvicorn running on http://127.0.0.1:8000` 和 `Application startup complete` 的文字。此时终端一直被服务占用是正常的，不是卡住。让它保持运行；需要输入其他命令时新建一个终端。

命令含义：`learning_examples.first_api` 对应文件 `learning_examples/first_api.py`；`:app` 指里面叫 `app` 的程序；`127.0.0.1` 指你的电脑；`8000` 是它接收请求的编号；`--reload` 用于开发时保存代码后重启练习服务，**它不是业务插件热插拔**。

## 8. 在浏览器检查结果

依次把下面的地址粘贴到浏览器地址栏：

```text
http://127.0.0.1:8000/health
http://127.0.0.1:8000/products
http://127.0.0.1:8000/products?max_price=200
http://127.0.0.1:8000/products?max_price=100
http://127.0.0.1:8000/docs
```

预期：

| 地址 | 应该看到什么 |
|---|---|
| `/health` | `{"status":"ok","mode":"learning"}`，表示练习服务能响应 |
| `/products` | 2 件 200 元以内的商品：189 元耳机、99 元鼠标 |
| `max_price=200` | 同样返回 2 件；商品显示价格以整数分保存，例如 18900 |
| `max_price=100` | 只返回 99 元鼠标 |
| `/docs` | 接口试用页面，可以展开 `GET /products` 操作 |

在 `/docs` 展开 `GET /products`，点 `Try it out`，将 `max_price` 设成 `100`，再点 `Execute`。下面的 `Response body` 应只出现鼠标。`Response code` 为 `200` 表示请求成功；不要和商品预算 200 元混淆。

这里用的查询参数和自动接口文档机制可参考 [FastAPI 第一步](https://fastapi.tiangolo.com/zh/tutorial/first-steps/) 与 [查询参数](https://fastapi.tiangolo.com/zh/tutorial/query-params/)。

## 9. 做三个小实验

1. 地址改成 `max_price=50`：返回 `count: 0` 和空商品列表，说明没有满足预算的商品。
2. 地址改成 `max_price=-1`：应得到参数校验错误；HTTP 状态码为 `422`，说明负预算被拦截。
3. 在 `first_api.py` 把耳机名称改成“我修改的耳机”，保存，再刷新商品地址：应看到新名称。

今天的接口只能按预算过滤，没有语义理解、库存查询或登录。后面会分关卡补齐。

## 10. 停止和下次启动

回到运行服务的终端，按 `Ctrl+C` 停止。关闭窗口也会结束前台服务。

下次打开 VS Code，进入项目目录，再执行第 7 步启动命令即可。不必重装 Python、重新创建虚拟环境或重装依赖。

跑通之后记录依赖：

```powershell
.\.venv\Scripts\python.exe -m pip freeze | Set-Content -LiteralPath '.\learning_examples\requirements.lock.txt' -Encoding UTF8
```

这个文件记录本次实际安装版本，方便以后复现。新环境可用 `-m pip install -r .\learning_examples\requirements.lock.txt` 安装相同版本。

## 常见问题

| 报错/现象 | 先做什么 |
|---|---|
| `can't open file` 或路径不存在 | 用 `Get-Location` 检查目录；确认左侧能看到 learning_examples |
| `.venv\Scripts\python.exe` 找不到 | 检查当前目录；确认第 4 步执行成功 |
| `No module named fastapi` 或 `uvicorn` | 用第 5 步安装；启动时使用 `.venv` 的完整路径 |
| `Could not import module` | 从项目根目录启动；确认是 `learning_examples.first_api:app` |
| `WinError 10048` / 端口占用 | 先检查是否已经启动了一份服务；也可把命令端口改为 8001，浏览器地址同步改为 8001 |
| 浏览器访问不了 | 服务终端是否还在运行；地址是否以 `http://127.0.0.1` 开头；查看终端报错 |
| 访问根地址 `/` 显示 404 | 正常，练习没做首页；访问 `/health`、`/products` 或 `/docs` |
| 编辑器波浪线提示缺少包 | 按第 6 步选 `.venv` 解释器；先看实际运行是否成功 |
| 安装时出现网络/证书错误 | 保留完整错误，确认网络连接后再排查；不要随意关闭证书校验 |
| 出现 `>>>`，命令输入后报语法错误 | 你进入了 Python 交互窗口；输入 `exit()` 回到 PowerShell 后执行命令 |
| 中文显示乱码 | VS Code 右下角文件编码设为 UTF-8；复制输出时保留原文 |

如果以后换电脑，没有 `py -3.13`，先去 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/) 安装适用的 64 位 Python，并验证版本。当前电脑已装好，不需要重复安装。
