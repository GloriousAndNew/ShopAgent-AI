## 与初始计划的取舍

- 按用户选择实现 Mock 模式，真实模型留到后续接入。
- 使用电脑已有 Python 3.13；原计划为 3.12。
- 认证采用数据库可撤销、8 小时有效的不透明令牌，未增加 JWT 依赖。
- 当前政策为关键词检索，保留版本和文本引用；没有向量检索。
- 网页采用普通 JSON 请求结果，未实现 SSE 文本流。
- 使用本机单宿主与预配置插件白名单；不含多机发布、任意远程代码包安装或不兼容数据库热迁移。
- 商品 1.1.0 是独立兼容实现样例，其他插件 1.1.0 复用相同业务代码用于验证进程替换。

启动、停止与演示操作见根目录 README 和 [新手使用说明](./MVP新手使用说明.md)。
