# 咨询数据告知与运行维护指南

更新：2026-10-10。适用于当前本地 MVP，尚未上线。

本轮增加三件事：顾客进入前了解数据用途，商家决定何时清理过期访客咨询，后台查看模型和程序异常。

## 顾客怎么进入

1. 打开 `/customer`，展开“咨询数据与 AI 使用说明”。
2. 阅读保存内容、真实模型外发、访客凭据有效期和人工回复方式。
3. 勾选“我已阅读并了解以上说明”，点击“开始咨询”。
4. 进入后仍可在聊天页展开同一说明。

当前启用的服务为 DeepSeek 时，说明会标明 DeepSeek；规则测试模式会说明不发送给模型。其他兼容模型只显示商家配置的服务，具体经营者和服务商信息仍需商家在上线前确认。

正式模式由服务器强制检查说明版本；未了解、未提交当前版本时不能创建访客。访客创建与阅读记录在一个数据库事务中完成，设置变化导致旧版本失效时，会要求刷新阅读。修改保留设置后说明版本更新。

开发模式保留空请求的测试 API 兼容性；网页入口仍要求阅读。这不代表开发模式可以直接公开使用。

原来已经创建的访客凭据仍按原8小时期限到期，不自动撤销；他们刷新页面可以阅读更新后的说明。本版没有长期账号或跨设备找回功能。

人工咨询通过本机业务接口登记，不必让模型处理；真实 AI 咨询会按说明发送必要内容。不要发送密码、支付信息或完整身份证信息。

## 商家如何设置保留期限

打开 `/merchant`，展开 **数据保留与运行监控**。

**目前自动清理关闭，默认预览期限90天。关闭时不会自动删除咨询，也不会自动删除过期凭据。** 我没有为你启用清理。

- “无活动保留期限”可设7至365天。
- 点击“刷新预览与监控”，按已保存期限查看下一批候选数量。
- 更改输入框但未保存时，预览仍使用旧设置。
- 确定真实店铺保留安排、备份和人工处理流程后，才勾选启用并保存。
- 启用时页面会再次确认永久删除范围；不启用也可以保存期限。

启用后，宿主每分钟检查是否该执行，每次执行之后至少一小时才再自动执行。启动/启用后首次符合条件的执行可能在一分钟内开始。每批最多200个会话，积压数据分批处理。

“立即执行一批清理”只在启用时可用，执行前再次确认。删除不能在网页撤销；备份恢复会回到备份时刻，并可能恢复已经删除的记录，须重新核对保留安排。

## 哪些记录可以清理

一个会话须同时满足全部条件：

1. 归属于随机访客账号 `guest_...`，不是正式管理员或其他买家账号。
2. 会话创建时间早于期限，最近期限内没有消息、工单创建、人工回复、关闭或重开事件。
3. 访客没有有效登录凭据。
4. 所有关联工单已关闭；“待处理”和“已回复但未关闭”都会保留。
5. 当前宿主没有正在处理该会话的请求锁。

清理在单个事务中删除会话、消息及关联已关闭工单、人工回复、状态事件。过期登录凭据一并清理；没有剩余会话、工单或有效凭据的随机访客账号及其阅读记录才删除。

商品、库存、政策、优惠、正式账号、每日模型调用计数均不属于清理范围。未关闭工单可能长期保留，商家需要实际处理并决定是否关闭。

预览不是锁定清单，执行时会重新判断。新回复、重新打开工单、设置版本变化可能使执行数量少于预览；设置冲突会拒绝执行。

清理作用于当前数据库中的逻辑记录，不保证清除 SQLite 空闲页、磁盘副本、模型服务已有记录或历史备份。备份保留和服务商记录需要另行管理。不要把此功能理解成所有副本的彻底擦除。

## 如何查看异常

后台同一面板提供：

- 最近24小时各类已记录事件的次数。
- 最近几条事件的时间和类别。
- 当前处于 failed 状态的业务模块。
- 最近一次清理时间及删除数量。

点击“刷新预览与监控”更新。事件只保留最近1000条，汇总是这部分记录中最近24小时的次数；高流量时不是完整统计报表。

| 显示事件 | 可以先检查什么 |
|---|---|
| 模型认证失败 | 在本地核对密钥和权限，不把密钥发到聊天 |
| 模型超时、不可用 | 接口、网络与服务状态；顾客先登记人工 |
| 每日调用额度用完 / AI暂停 | 这是运营限制；查看额度与开关，不一定是故障 |
| Agent 达到上限 | 缩小问题范围，或联系人工 |
| 自动维护失败 | 查看目录权限、数据库状态；先保持清理关闭 |
| 模块 failed | 到技术模块查看状态；先确认原因再启用 |

事件表不保存顾客问题、回答、密钥、身份或原始异常文字，未知错误码归为固定通用类别。这是本地运行事件记录，没有短信、邮件、外部告警推送或全天值守。

没有事件不代表系统始终健康：进程停止、磁盘不可写时，事件可能无法记录。服务器部署后仍要配外部健康检查和人工查看日志。

## 上线前还要准备

- 商家自己的真实经营者、联系方式、人工值守安排及数据保留期限。
- 正式管理员和已审核的真实商品、政策。
- 真实模型配置与服务商记录处理安排。
- 服务器、域名、公网证书和外网验收。
- 定期备份、异地副本安排及外部故障检查。

当前页面是本程序的数据使用告知，不能替代商家实际经营信息。下一步可先做整体验收清单与部署文件整理，不需要先购买服务器。
