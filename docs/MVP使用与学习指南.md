# MVP 使用与学习指南

你可以先把它理解成一个客服小团队：顾客只找主客服，主客服再找三个专业助手。助手不能凭记忆回答价格和库存，必须查工具。

## 五个词，先分清

| 名字 | 用途 | 对应本项目 |
|---|---|---|
| 网页 | 顾客输入问题、看答复 | 顾客咨询 |
| 主 Agent | 看懂问题，安排谁处理，汇总回答 | MainAgent |
| 专业 Agent | 用模型理解任务，选择自己有权限的工具 | ProductAgent、OrderAgent、RecommendAgent |
| 工具模块 | 执行具体操作，不自由编造答案 | 商品、订单、物流、政策、售后、导购服务 |
| 数据库 | 保存商品、本人订单、聊天和申请 | data 中的 SQLite 文件 |

例子：“P001 黑色还有货吗？”网页交给主客服；主客服安排商品 Agent；它调用 check_inventory；商品模块查数据库得到12件；Agent 把结果变成中文回答。

“热插拔”指运行时停用/启用一个工具模块，或者切换兼容版本。停掉物流，商品和订单仍可查，但物流能力不可用。依赖下层模块的服务不能继续工作，所以有依赖检查。Agent 角色和工具模块是两层，本版 Agent 角色配置在代码中，工具模块可以在后台运行时切换。

## 三个页面

1. **顾客咨询**：这是顾客真正使用的功能，提问、查卡片、确认草稿、查看人工回复。
2. **系统说明**：帮助你看懂四个角色和一次复杂咨询的分工，不包含模型隐藏思考过程。
3. **商家后台**：管理员回复顾客；下方折叠区调整模型或工具模块。

## 建议的开发和学习顺序

### 第一步：跑通一条商品查询

打开网页问“P001 黑色还有货吗”。观察协作记录和库存卡片。先掌握输入→分派→查询→回复，不急着改代码。

### 第二步：读 Python 最基础的语法

学变量、列表、字典、函数、模块、异常。用 `learning_examples` 做已有练习。读官方 [Python 入门教程](https://docs.python.org/zh-cn/3/tutorial/)，先读第3、4章；不需要一次读完整个网站。

### 第三步：从一个工具开始读代码

打开 `shopagent/plugins/product/service.py`，看 Inventory 如何限制输入、inventory 如何查询、TOOLS 如何登记。价格保存为整数“分”，18900表示189元。

### 第四步：理解网页请求

网页 POST /chat 把问题发给服务器；服务器返回 JSON（有固定字段的数据）。`shopagent/app/main.py` 是入口。学习 FastAPI 官方教程的路径操作、请求体、依赖注入。身份由登录后的服务器确定，顾客不能在工具参数里填“我是其他用户”。

### 第五步：理解 Agent 分工

`shopagent/agents/registry.py`：每个专业角色能用哪些工具。
`shopagent/agents/main.py`：主客服生成任务列表并串行分派。
`shopagent/core/llm_agent.py`：专业助手循环调用模型和工具，这是复用的执行器。

不要把 Agent 当作四个互相自由聊天的机器人。它们按主客服安排的任务交接，工具权限受程序限制。

### 第六步：理解导购协作

发送“推荐200元以内的降噪耳机，查黑色库存，再算优惠价”。预期是导购筛选候选→商品查库存→导购查活动和算价。首轮导购不允许提前算价；后轮不重复筛选；整轮有调用上限。

### 第七步：验证安全和独立模块

Alice 查 O2001 应得到未找到/不属于本人。停用导购后商品仍可查。售后只创建草稿，由顾客确认提交。运行测试后再修改，不要直接改数据库来掩盖问题。

### 第八步：接入真实店铺再上线

先换商品数据，再换本人订单与物流接口，然后接真实店铺政策。最后处理正式账户、密钥管理、限流、备份、HTTPS和部署。生产账户不能使用本版公开的示例密码。

## 你当前不需要做的配置

DeepSeek 已配置，沿用本地 `.env` 和 `agent.toml`。这轮重构没有要求你重新填密钥。业务还是示例；不要把示例优惠或模拟退款当成真实业务承诺。
