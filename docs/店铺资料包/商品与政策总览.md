## 变成真实店铺资料前，你要补哪些内容

- [ ] 店铺正式名称、经营主体、人工联系人。
- [ ] 每款商品的真实名称、品牌、规格依据、标价、图片及当前SKU库存。
- [ ] 保修和售后依据，不把所有产品写成统一一年。
- [ ] 发货地、配送范围、费用、承运商与发货时限。
- [ ] 是否有真实优惠及有效期；没有则保持关闭。
- [ ] 退货地址、联系人、质量检测和售后处理流程。
- [ ] 人工服务时间与查看回复方式。
- [ ] 隐私说明、聊天保存期限和处理渠道。
