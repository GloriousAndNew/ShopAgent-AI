正式经营时，应按适用的七日无理由退货规则处理适用商品；必要查验导致的拆封或合理调试不能一概视为不完好。因此本草案不采用“只要拆封就不能退”的判定。商品是否适用及其完好情况需结合商品资料与实际状态核实。[依据：暂行办法第六至十条](https://www.samr.gov.cn/cms_files/filemanager/samr/www/samrnew/samrgkml/nsjg/fgs/202011/W020211116307515971754.pdf)。
资料包不为任何商品预设“不支持七日无理由退货”的标签。存在例外时需核实适用条件和购买流程中的告知/确认要求，不能由Agent临时创建例外。
开发流程：询问订单、商品、原因、收货情况与必要的完好信息 → 查所属订单及适用政策 → 生成草稿 → 顾客明确确认 → 商家或真实平台处理。
当前未接真实订单，不受理真实退款或寄件。商家待填写实际退货地址、联系人、联系电话、完整完好检查流程。不要让顾客把商品寄到虚构地址。
