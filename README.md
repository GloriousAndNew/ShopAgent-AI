# ShopAgent AI · 按原文重构的 MVP

先看这一个入口。当前版本用 **主客服 + 商品 Agent + 订单 Agent + 导购 Agent**，处理顾客咨询。已复用原项目的登录、会话、业务服务、售后确认、人工回复、独立进程热插拔和 DeepSeek 接入代码。

这是可以在你电脑上运行的 MVP。模型使用本地配置的 DeepSeek；商品、订单、物流和活动还是示例数据。**尚未部署到公网，不能把 localhost 链接发给外部顾客使用。**

## 先体验，不用先学代码

新增独立入口：[顾客咨询](http://127.0.0.1:8000/customer)无需注册，点击开始咨询；[商家入口](http://127.0.0.1:8000/merchant)登录管理员处理咨询。顾客可在“我的人工咨询”查看回复和未读提示。原首页仍保留完整业务演示。当前两个新入口仍是本地试运行，不能向外部顾客分享localhost链接。

1. 双击 **启动ShopAgent.cmd**，等待 `Application startup complete`。
2. 打开 [客服网页](http://127.0.0.1:8000/)。已在运行时直接刷新页面。
3. 选 Alice，密码 `demo123`。这是示例账户。
4. 在“系统说明”看四个角色，在“顾客咨询”发送下面的问题。

| 试着问 | 会做什么 |
|---|---|
| 200元以内的降噪耳机有哪些？ | 商品 Agent 查商品 |
| 比较 P001 和 P002 的价格 | 商品 Agent 查店内标价并比较 |
| 推荐200元以内的降噪耳机，查黑色库存，再算优惠价 | 导购 → 商品 → 导购，串行协作 |
| 我的订单 / O1001 到哪了 | 订单 Agent 查本人订单或物流 |
| 申请退货 O1002，已拆封，质量问题耳机没声音 | 订单 Agent 查订单和政策，生成草稿；你点击确认才提交模拟申请 |
| 转人工 | 创建咨询；管理员回复后，在原会话点击“查看客服回复” |

每条新 AI 回答可以展开 **Agent 协作记录** 和 **处理记录**。旧聊天记录保留当时的结果，不会被改造成多 Agent。

商家操作：退出后选 Admin，同一示例密码。“商家后台”可进入商品管理、政策管理和优惠管理，维护资料，保存草稿后再发布；人工回复仍在后台。模型设置、模块启停放在两个折叠区中。普通顾客不需要理解这些技术设置。

停止：双击 **停止ShopAgent.cmd**。不要删除 `.env`、`agent.toml` 或 `data`；它们分别保存密钥、模型配置和已有数据。

## 开发者运行与验证

需要 Python 3.12–3.13，本机使用 3.13。PowerShell 在本目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 -m shopagent.run
```

验证：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q
```

测试使用临时数据库、独立端口和模型桩，不消费真实模型额度。启动时会保留原业务数据。真实网页咨询会调用 DeepSeek，按平台账单计费。

模型名称、地址和模式在 `agent.toml`；密钥只在本地 `.env`。不要把 `.env` 提交或发给别人。
